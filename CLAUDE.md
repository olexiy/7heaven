# 7Heaven — правила работы над проектом

Тактическая RPG-симуляция: реальное время с паузой, каналы тела, конвейер модификаторов. Прототип боевой механики в браузере.

## Документы — источник правды
- `docs/GDD.md` — лор и механики. Только дизайн, ни слова о технологиях.
- `docs/TECH.md` — архитектура и план реализации.
- `docs/MVP.md` — границы текущего прототипа и критерии готовности.
- `LOG.md` — журнал разработки человеческим языком + текущее состояние вверху. **Читать первым после сжатия контекста или перезапуска.**
- `docs/archive/` — старые версии, не редактировать.

Правило: дизайн и техника не смешиваются. Изменение механики → GDD, изменение реализации → TECH.

## Архитектура (кратко, подробно в TECH.md)
- `src/core/` — чистый TypeScript, **никаких импортов из DOM**. Детерминированная симуляция: фиксированный тик 50 мс, одно семя RNG, журнал команд.
- `src/data/` — правила как данные (действия, умения, враги, модификаторы).
- `src/render/` — Canvas 2D за интерфейсом Renderer. Изометрия только здесь.
- `src/ui/` — DOM-панели и ввод.
- `src/app/` — склейка.
- `tools/sim-cli.ts` — прогон боёв без экрана.
- `tests/` — Vitest.

## Команды
- `npm run dev` — dev-сервер (порт 5173).
- `npm test` — тесты ядра.
- `npm run sim` — прогон боёв, отчёт по балансу.
- `npm run build` — статический билд в `dist/`.

## Процесс
- Работа вертикальными срезами (список в TECH.md §6). Каждый срез оставляет игру запускаемой.
- Срез готов, когда: тесты зелёные, прогон боёв (если трогает бой) в норме, скриншот в браузере подтверждает картинку.
- После каждого среза: запись в `LOG.md`, скриншот в `docs/screenshots/`, коммит, push.
- Коммиты на русском, кратко: `срез 2: каналы, удар мечом, кольцо`.
- При проблемах искать решения онлайн разрешено.
- Субагенты — для независимых модулей; интеграция всегда в одном потоке.

## Отладка в браузере
- Панель встроенного браузера в скрытом состоянии имеет viewport 0×0: rAF не идёт, клики по холсту не доходят.
- Симуляцию гонять через `window.game.advance(сек)`, команды через `window.game.sim.command(...)`.
- Скриншот в `docs/screenshots/`: сначала мелкий `computer screenshot` (панель становится видимой), затем сразу `await window.game.shot('имя')`.

## Стиль кода
- TypeScript strict, без `any`.
- Длительности в ядре — в тиках (целые), наружу — в секундах.
- Случайность только через `sim.rng`. `Math.random` в `src/core` запрещён.
- Числа правил только в `src/data`, не в коде ядра.
- Комментарии и имена в коде — английские; тексты интерфейса — русские.
