# 7Heaven

Тактическая RPG-симуляция: бой в реальном времени с паузой, каналы тела (ноги и руки действуют одновременно), конвейер модификаторов вместо таблиц правил. Прототип боевой механики в браузере.

- Дизайн: [docs/GDD.md](docs/GDD.md)
- Реализация: [docs/TECH.md](docs/TECH.md)
- Границы прототипа: [docs/MVP.md](docs/MVP.md)
- Журнал разработки: [LOG.md](LOG.md)

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:5173. Параметр `?seed=123` фиксирует рифт.

## Управление

| Клавиша | Действие |
|---|---|
| Пробел | пауза |
| 1 / 2 / 3 | скорость ×1 / ×2 / ×5 |
| клик по клетке | идти |
| Q / W | действия: меч, удар ногой (затем клик по врагу) |
| E / F / R | приёмы: щит, удар щитом, огненный шар (затем клик по цели) |
| клик по кольцу над героем | отменить действие этого канала |
| T | автоатака: свободные руки и ноги сами бьют врага рядом |
| A | автопилот |
| Esc | снять выбор действия |

## Проверки

```bash
npm test          # тесты ядра и правил
npm run sim       # 300 боёв без экрана, отчёт по балансу
npm run build     # статический билд в dist/
```

Ядро (`src/core`) не зависит от браузера: фиксированный тик 50 мс, одно семя случайности, журнал команд. Любой забег воспроизводится тик в тик.
