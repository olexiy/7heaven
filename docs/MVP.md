# 7Heaven — MVP v0.1: границы прототипа

> Версия: 0.2 (урезано по замечаниям автора)
> Дата: 04.09.2026
> Цель: **играбельная версия боевой механики**. Не контент, не красота, не прогрессия между забегами. Один рифт, в котором чувствуется время, каналы, конвейер и кольца.

---

## 1. Что входит

### Мир
- Один рифт, процедурная карта: 5–6 комнат и коридоры на сетке около 30×30.
- Туман войны: видимость по радиусу от Восприятия, стены закрывают обзор. Увиденные клетки остаются на карте затемнёнными.
- Точка выхода. Подойти → подтверждение → «рифт пройден» с итогом: время, убито, получено опыта.
- Смерть → «рифт провален», перезапуск с новым семенем.

### Персонаж
- Два канала: **Ноги** и **Руки** (руки и разум объединены в MVP).
- Атрибуты фиксированные, без роста: Сила, Ловкость, Мудрость, Восприятие.
- Мана: **100 единиц внутреннего запаса**, без регенерации в рифте, без сифона и мана-умений.
- Четыре умения с ростом по правилу вызова прямо в забеге: Меч, Ближний бой, Щит, Огонь. Рост виден как ускорение действий.

### Действия
| Действие | Канал | База |
|---|---|---|
| Шаг | ноги | 1.0 с на клетку, путь по клику |
| Удар мечом | руки | 2.0 с, 15–25 урона |
| Удар ногой | ноги | 1.0 с, 5–10 урона, прерывает накопление |
| Щит | руки | 0.5 с подъём + 5 с, −70 % урона |
| Огненный шар | руки | 3 фазы × 5 с, 30 маны, 30–50 урона |

- Кольца над персонажем и врагами: по кольцу на канал, сектора фаз, цвет по типу.
- Отмена действия кликом по кольцу в паузе. Потеря по фазе: накопление теряет собранное, формирование теряет всё.

### Конвейер (обязательный минимум модификаторов)
- Движение × 20 к шансу срыва формирования.
- Уровень умения → длительность действия.
- Попадание против уклонения: цель не уклоняется, если не видит атаку или её ноги заняты.
- Щит режет урон только пока поднят.
- Удар ногой прерывает только фазу накопления.

### Время
- Пауза, ×1, ×2, ×5.
- Автоперемотка: если врагов не видно и действие длинное, предлагается ускорение; враг замечен → ×1 и пауза.

### Враги
- Один тип, 2–3 экземпляра, разные значения Восприятия (один «глухой», один «чуткий»).
- Состояния: не заметил / в бою. Переход по видимости и по шуму.
- Действия: шаг, удар. Те же правила, те же кольца.

### Автопилот
- Переключатель. Приоритеты: добить слабого → щит при HP < 30 % → атаковать ближайшего. Без запоминания привычек.

### Интерфейс
- Полоски HP и маны, четыре уровня умений, кнопки действий, кнопки скорости, индикатор паузы, мини-лог событий.
- Словесная оценка на кольце в паузе: «уверенно / рискованно / безнадёжно».

---

## 2. Что не входит

Комната, билеты, предметы и инвентарь, снаряжение, крафт, привычки, мана-умения и сифон, Удержание, разделение рук, ритуалы, пороги умений, рост атрибутов, сохранение, звук, спрайты.

## 4. v0.2 — ритм боя (04.09.2026, по итогам первой оценки)

Проблема v0.1: после контакта бой был гонкой урона без решений. Добавлено:

- **Восстановление** после действий и приёмов (меч 1 с, нога 5 с, щит 4 с, удар щитом 8 с, фаербол 3 с). Симметрично для врагов.
- **Автоатака**: свободные каналы сами бьют врага рядом базовыми действиями; приёмы только вручную. Переключатель.
- **Три канала**: ноги, правая рука, левая рука. Щит и меч работают одновременно; заклинание занимает обе руки.
- **Блок**: поднятый щит отбивает удар целиком с шансом от навыка Щита, иначе режет 70 %.
- **Удар щитом** — новый приём, сильное прерывание.
- **Направление взгляда**: удар в спину нельзя увернуть и заблокировать; разворот стоит 0.3 с.
- **Шаман**: враг-кастер с 6-секундной «Порчей», держит дистанцию. Прерывание наконец нужно.
- **Фаербол** 9 с вместо 15, урон 35–55.
- **Пауза по приёму врага**: опция, включена по умолчанию.

Статус: 86 тестов зелёные; `npm run sim` против трёх гулей и шамана даёт 59 % побед; прерываний 0.11 на рифт (было 0).

## 5. Отклонения прототипа от GDD

Упрощения, принятые ради скорости. GDD остаётся целевым дизайном; здесь список того, что в коде иначе.

| В GDD | В прототипе | Почему |
|---|---|---|
| Четыре канала: ноги, правая, левая, разум | Три: разум слит с руками, заклинание занимает обе руки | Разум нужен только когда появятся действия «думать и делать» одновременно |
| Прерывание: `30 % × навык ÷ Стойкость цели` | `30 % + 3 % × навык атакующего`, Стойкости нет | Навык Стойкости не в MVP |
| Контроль маны — отдельный навык | Его роль играет навык Огня (каждый уровень режет шанс срыва на 8 %) | Мана-навыки исключены из MVP автором |
| Удар ногой на высоком уровне замедляет фазу, даже если не прервал | Не реализовано | Не нужно для проверки концепта |
| Автоперемотка «предлагает» ускорение до события | Включается сама, когда врагов не видно и герой занят; враг замечен → ×1 и пауза | Проще и ощущается лучше; кнопка «Перемотка» выключает |
| Мана: ядро и сифон | 100 единиц без регенерации | Решение автора для MVP |
| Атрибутов шесть, растут от навыков | Шесть значений есть, но используются Сила (урон), Ловкость (точность, уклонение), Восприятие (реакция); роста нет | Рост атрибутов вне MVP |
| Промах заклинания «может промахнуться» | Шанс промаха растёт с дистанцией: 3 % за клетку | Нужно правило, GDD его не задавал; предлагается внести в GDD |
| Блок «шанс от навыка Щита» | 15 % + 4 % за уровень, невозможен со спины | Числа для настройки, в GDD их и не должно быть |
| Реакция автопилота `база ÷ Восприятие` | `база × 10 ÷ Восприятие`: значение 10 считается средним | Та же формула, нормировка |
| Пороги навыков, привычки, Удержание, крафт, комната | Нет | Вне MVP по решению автора |
